## Overview

This application provides accurate second-hand vehicle valuations based on multi-variable inputs such as manufacturing year, mileage, brand, fuel type, and transmission type. It features real-time dynamic charts and automated report generation.

## Key Capabilities

- **Predictive Pricing Engine**: Multi-variable estimation using statistical and machine learning models.
- **Interactive Visualizations**: High-performance interactive charts powered by Plotly for market distribution and depreciation curves.
- **Data Export & Reporting**: Automated Excel spreadsheet report generation with styled formatting.
- **Responsive Web GUI**: Clean, minimalist, and responsive user interface built with Streamlit.

## Technology Stack

- **Framework**: Streamlit
- **Analytics & Math**: Pandas, NumPy, Scikit-Learn
- **Visualization**: Plotly Graph Objects
- **Spreadsheet Automation**: OpenPyXL

## Quick Start

```bash
# Clone the repository
git clone https://github.com/IkhsanFreya/prediksi-harga-mobil.git
cd prediksi-harga-mobil

# Install dependencies
pip install -r requirements.txt

# Launch application
streamlit run app.py
```
